## Parakeet TDT 0.6B v3

Cobra downloads the converted
[Parakeet TDT 0.6B v3 CoreML model](https://huggingface.co/FluidInference/parakeet-tdt-0.6b-v3-coreml),
based on [NVIDIA Parakeet TDT 0.6B v3](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3).
Both model cards identify the model license as Creative Commons Attribution
4.0 International: <https://creativecommons.org/licenses/by/4.0/>.

The model is downloaded separately on first launch and is not included in this
source repository.
